# GeoPicks beta downloads

GeoPicks is desktop subsurface-mapping software for geologists, independents and consultants. Pick tops directly on scanned (raster) well logs, correlate across sections, tie wells to 2D and 3D seismic, contour structure and isopach maps, and export a prospect pack. It runs entirely on your own Mac or Windows PC; your data never leaves your machine.

This repository only hosts the beta installers. It contains no source code. GeoPicks needs a license key to run; beta testers receive a free 6-month key by email.

More information and beta sign-up: https://getgeopicks.com

## Download (always the newest beta)

- **Mac:** [GeoPicks-mac.dmg](https://github.com/reecejk/geopicks-beta/releases/latest/download/GeoPicks-mac.dmg)
- **Windows:** [GeoPicks-windows-setup.exe](https://github.com/reecejk/geopicks-beta/releases/latest/download/GeoPicks-windows-setup.exe)

All versions: [Releases](https://github.com/reecejk/geopicks-beta/releases)

## Install on a Mac

1. Open the downloaded `.dmg` and drag **GeoPicks** into **Applications**.
2. The beta app is not yet signed by Apple, so the first time, **right-click (or Control-click) GeoPicks in Applications and choose Open**, then click **Open** again.
3. On macOS Sequoia (15) or later, if you only see "Move to Trash" / "Done": click **Done**, then go to **System Settings > Privacy & Security**, scroll down, and click **Open Anyway** next to the GeoPicks message. Confirm with your password.
4. After the first launch it opens normally.

## Install on Windows

1. Run `GeoPicks-windows-setup.exe`.
2. The beta installer is not yet code-signed, so Windows SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.
3. Follow the installer, then start GeoPicks from the Start menu.

## Activate

When GeoPicks opens, paste the beta license key emailed to you (it starts with `GP1.`) on the Activate page. Activation works offline. The Bear Head Creek demo project is preloaded so you can try it right away.
